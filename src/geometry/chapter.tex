	\subsection{Center of Mass}
		For a simple polygon (convex or not) with signed area $A = \frac{1}{2}\sum_{i=0}^{n-1} c_i$, $c_i = x_i y_{i+1} - x_{i+1} y_i$, indices mod $n$:
		\[ C_x = \frac{1}{6A}\sum_{i=0}^{n-1} (x_i + x_{i+1})\, c_i, \quad C_y = \frac{1}{6A}\sum_{i=0}^{n-1} (y_i + y_{i+1})\, c_i \]
		Use the signed $A$ (orientation cancels out). See \texttt{polygonCenter}.
